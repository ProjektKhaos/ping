# Ping Flood Watch V1.2

Production mobile PWA for nine ordered Ping River stations, an interactive OpenStreetMap station map, upstream rainfall and reliable Web Push alerts in Chiang Mai. P.1 remains the official main reference; each device can choose its preferred home display station and light, dark or system theme. The app is live at [ping.aberg.online](https://ping.aberg.online). Automated hardening is complete; real-device Android/iPhone push acceptance remains explicitly pending in `docs/TEST_REPORT.md`.

See `docs/INSTALL.md`, `docs/PROVIDERS.md`, `docs/WEATHER.md`, `docs/ALERTS.md`, `docs/API.md`, and `docs/TEST_REPORT.md` for architecture, sources, operations and verification.
